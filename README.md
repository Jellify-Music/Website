# Jellify Website

The website for [Jellify](https://github.com/Jellify-Music/App), live at [jellify.app](https://jellify.app).

Built with [TanStack Start](https://tanstack.com/start) and [Tamagui](https://tamagui.dev), and deployed to [Cloudflare Workers](https://developers.cloudflare.com/workers/).

## Getting Started

Use [Bun](https://bun.sh) (the version in `package.json`'s `packageManager`) and the Node version in `.nvmrc`. Vite and Wrangler run on Node.

```bash
nvm use
bun install
bun run dev
```

Then open [http://localhost:3000](http://localhost:3000).

## Project Structure

| Path                    | What's there                                                                 |
| ----------------------- | ---------------------------------------------------------------------------- |
| `src/routes/`           | File-based routes. `__root.tsx` is the HTML shell, `index.tsx` is `/`        |
| `src/routeTree.gen.ts`  | Generated by the TanStack Router plugin, don't edit by hand                  |
| `src/tamagui.config.ts` | Tamagui tokens, fonts and themes, mirroring the Jellify app's "purple" theme |
| `public/`               | Static assets served as-is                                                   |
| `wrangler.jsonc`        | Cloudflare Workers configuration                                             |

Light and dark themes follow the visitor's system preference.

## Scripts

| Command                  | Description                                                            |
| ------------------------ | ---------------------------------------------------------------------- |
| `bun run dev`            | Start the dev server (runs in the Workers runtime)                     |
| `bun run build`          | Production build into `dist/`                                          |
| `bun run preview`        | Build and serve the production build locally                           |
| `bun run lint`           | Lint with ESLint                                                       |
| `bun run typecheck`      | Typecheck with TypeScript                                              |
| `bun run deploy`         | Build and deploy to Cloudflare Workers                                 |
| `bun run deploy:version` | Build and upload a new Worker version without promoting it             |
| `bun run cf-typegen`     | Regenerate `worker-configuration.d.ts` after changing `wrangler.jsonc` |
