# Jellify Website

The website for [Jellify](https://github.com/Jellify-Music/App), live at [jellify.app](https://jellify.app).

Built with [TanStack Start](https://tanstack.com/start) and [Tamagui](https://tamagui.dev), and deployed to [Cloudflare Workers](https://developers.cloudflare.com/workers/).

## Getting Started

Use the Node version in `.nvmrc` and Yarn 1:

```bash
nvm use
yarn install
yarn dev
```

Then open [http://localhost:3000](http://localhost:3000).

## Project Structure

| Path                    | What's there                                                                 |
| ----------------------- | ---------------------------------------------------------------------------- |
| `src/routes/`           | File-based routes. `__root.tsx` is the HTML shell, `index.tsx` is `/`        |
| `src/routeTree.gen.ts`  | Generated by the TanStack Router plugin, don't edit by hand                  |
| `src/tamagui.config.ts` | Tamagui tokens, fonts and themes, mirroring the Jellify app's "purple" theme |
| `public/`               | Static assets served as-is                                                   |
| `wrangler.jsonc`        | Cloudflare Workers configuration                                             |

Light and dark themes follow the visitor's system preference.

## Scripts

| Command               | Description                                                            |
| --------------------- | ---------------------------------------------------------------------- |
| `yarn dev`            | Start the dev server (runs in the Workers runtime)                     |
| `yarn build`          | Production build into `dist/`                                          |
| `yarn preview`        | Build and serve the production build locally                           |
| `yarn lint`           | Lint with ESLint                                                       |
| `yarn typecheck`      | Typecheck with TypeScript                                              |
| `yarn deploy`         | Build and deploy to Cloudflare Workers                                 |
| `yarn deploy:version` | Build and upload a new Worker version without promoting it             |
| `yarn cf-typegen`     | Regenerate `worker-configuration.d.ts` after changing `wrangler.jsonc` |
