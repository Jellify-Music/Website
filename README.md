# Jellify Website

The website for [Jellify](https://github.com/Jellify-Music/App), live at [jellify.app](https://jellify.app).

Built with [TanStack Start](https://tanstack.com/start) and [Tamagui](https://tamagui.dev), and deployed to [Cloudflare Workers](https://developers.cloudflare.com/workers/).

## Getting Started

Use the Node version in `.nvmrc` and npm:

```bash
nvm use
npm install
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000).

## Project Structure

| Path                    | What's there                                                                 |
| ----------------------- | ---------------------------------------------------------------------------- |
| `src/routes/`           | File-based routes. `__root.tsx` is the HTML shell, `index.tsx` is `/`        |
| `src/routeTree.gen.ts`  | Generated by the TanStack Router plugin, don't edit by hand                  |
| `src/tamagui.config.ts` | Tamagui tokens, fonts and themes, mirroring the Jellify app's "purple" theme |
| `public/`               | Static assets served as-is                                                   |
| `wrangler.jsonc`        | Cloudflare Workers configuration                                             |

Light and dark themes follow the visitor's system preference.

## Scripts

| Command                  | Description                                                            |
| ------------------------ | ---------------------------------------------------------------------- |
| `npm run dev`            | Start the dev server (runs in the Workers runtime)                     |
| `npm run build`          | Production build into `dist/`                                          |
| `npm run preview`        | Build and serve the production build locally                           |
| `npm run lint`           | Lint with ESLint                                                       |
| `npm run typecheck`      | Typecheck with TypeScript                                              |
| `npm run deploy`         | Build and deploy to Cloudflare Workers                                 |
| `npm run deploy:version` | Build and upload a new Worker version without promoting it             |
| `npm run cf-typegen`     | Regenerate `worker-configuration.d.ts` after changing `wrangler.jsonc` |
